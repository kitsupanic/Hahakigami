# Security policy

Hahakigami reads your whole disk and can move files to Trash, so security reports matter.

## Reporting a problem

Please report security problems privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue.

Include what you found, the steps to reproduce it, and the macOS and Hahakigami versions. You will get a reply as soon as possible, and credit in the fix if you want it.

## In scope

- Cleanup removing items outside the reviewed selection, or anything other than a move to Trash
- File paths or scan data leaving the machine
- Ways for a web page, file name or MCP/CLI input to run commands or reach files it should not

## Supported versions

Only the latest code on `main` is supported.
